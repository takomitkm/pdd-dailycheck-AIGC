# ADR-003：同一目标的第二胶囊标定框（`pill_channel`，缺省关闭）

- 状态：**已采纳（实现），标定值待批准后方可在生产 profile 中启用**
- 日期：2026-11-07
- 相关：`docs/refactor-v2/t18a-calibration-findings.md`、D08（标定改动需批准）

## 背景

真机演练（2026-11-07，h61 + `192.168.1.110:16132`）证实：同一个目标「抽福袋」在
**两种页型**上位置与可读性完全不同：

| 页型 | 「抽福袋」位置 | 整页 OCR | band 档 | pill 档（color ×2 psm7） |
|---|---|---|---|---|
| 福袋活动页 | 约 (100, 895)（现有 `bag.pill`） | 可认 | 可认 | — |
| 百亿补贴频道页 | **(435, 524)** | **认不出** | **认不出** | **认得出**（三词同行，conf 92.6） |

现有 `TargetSpec` 每个目标只有**一个** `pill` 框，无法同时表达两处。旧脚本靠「BACK 回到
频道页再认一次」间接处理，但那是流程补丁，不是标定能力。

## 决策

给 `TargetSpec` 增加**可选**字段 `pill_channel`（同一目标在频道页型上的胶囊框）：

- 缺省 `None` = 不启用 → **现有 profile 与所有标定值不变**，行为完全向后兼容；
- 值域与校验同 `pill`（四个 0..1 比例、x1<x2、y1<y2）；
- 流程段按**当前页型**选用：在频道页用 `pill_channel`，在活动页用 `pill`；
- 识别算法不变，只是多一处标定；仍是同一 `Candidate`/`LocateResult` 合同。

## 备选与否决

- **B：新增目标键 `bag_channel`**：不改 schema，但把「同一控件的两处位置」伪装成两个目标，
  流程要额外知道用哪个，且 `ALIAS/COORD/region` 要重复一份 → 否决。
- **C：把 `pill` 改成列表**：破坏现有 profile 结构与所有读它的代码/测试 → 否决。

## 后果

1. schema 字段增加（向后兼容，`schema_version` 仍为 1，因为老 profile 文件仍可解析）；
2. 生产启用前需要**批准频道页那颗的标定值**（候选：`[0.472, 0.375, 0.75, 0.4375]`，
   由真机实测反推，对应点击点 (435,524)）；
3. 观察层必须携带 band/pill 的**几何**（缩放/偏移），否则裁片坐标会被当成整页坐标——
   本 ADR 同时补齐该缺口（`FrameObservation.geometries`）。
